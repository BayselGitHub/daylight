# Daylight BLE PWA v3.3.0

- Automatically discovers and reattaches to previously granted Daylight BLE devices on page load/refresh.
- Supports simultaneous phone + PC sessions using the matching 32-bit client-tag transport.
- Sends task-start and timed-task-end desktop notifications when browser notification permission is enabled.
- Supports Beacio background notification registration and background connections on iPhone.
- Keeps the current HTTPS-hosted PWA shell lightweight; live task/shop/log data remains on the ESP32.
